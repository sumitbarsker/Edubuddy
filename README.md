# EduBuddy

EduBuddy is a web-based student dashboard made to help students manage their daily study activities in one place.

## Features
- Notes management
- Daily routine tracking
- Reminder system
- Study planning
- Easy-to-use dashboard 

## Technologies Used
- HTML
- CSS
- JavaScript

## Why I Built This
I created EduBuddy to make it easier for students to organize their notes, routines, and important academic tasks without using multiple apps.
